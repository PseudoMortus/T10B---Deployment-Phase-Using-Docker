# T10B - Deployment Phase Using Docker

## Objective for this Repository
### Outcome:
Learners containerize an application using Docker, deploy it successfully in a controlled environment, and document deployment, rollback, and basic operational procedures following industry best practices.

### Artifact:
 - Dockerized application (Dockerfile and supporting configuration)
 - Successfully deployed container
 - Deployment and rollback guide
 - Basic operational documentation including monitoring and troubleshooting notes
